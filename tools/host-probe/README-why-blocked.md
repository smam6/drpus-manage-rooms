# «چرا می‌گوید این متخصص رزرو دارد؟»

## این فایل را چرا دارم

پیام **«این متخصص در این ساعت قبلاً رزرو دارد. لطفاً ساعت دیگری را انتخاب کنید.»**
فقط وقتی تولید می‌شود که یک کوئری SQL واقعاً یک ردیف برگردانده باشد.

از بیرون، آن ساعت **خالی به نظر می‌رسد** — پس ردیف نامرئی است. یکی از این‌هاست:

| علت | چطور دیده می‌شود |
|---|---|
| ردیف با `order_id = 0` | `book #N ... order=0` → در لیست سفارش‌های ووکامرس نیست |
| ردیف با وضعیت خالی | `status=` خالی → برای همیشه قفل می‌کند |
| رزرو «حضوری» برای متخصص دیگر | `spec=` شماره‌ای که انتظار ندارید |
| رزرو تلفنی که اتاق را بسته | `office=phone_consultation` |
| ساعت غیرعادی (`00:00:00`) | همهٔ روز را می‌بندد |

## نصب

1. فایل `why-blocked.php` را در **همان پوشه‌ای که `wp-load.php` است** آپلود کنید
   (معمولاً `public_html/`).
2. با اکانت **مدیر** وارد شوید.
3. این آدرس را باز کنید:

```
https://آدرس-سایت-شما/why-blocked.php
```

4. برای بررسی یک ساعت مشخص:

```
https://آدرس-سایت-شما/why-blocked.php?date=2026-12-16&time=10:00&specialist=12&office=32c836b9-15c8-4d6e-ba83-140f8b5dcfbc
```

`specialist` = شمارهٔ ستون `id` در جدول `drplus_specialists` (نه post_id).
`office` = شناسهٔ کلینیکی که مشتری انتخاب کرده.

5. کل خروجی را کپی کنید.
6. **فایل را پاک کنید.**

## چه چیزی نشان می‌دهد

| بخش | معنی |
|---|---|
| ۱ | ماژول روشن است؟ حالت `room` یا `any`؟ |
| ۲ | **همهٔ ردیف‌های آن روز** — هر کدام `HOLDS` یا `free` |
| ۳ | ردیف‌های با ساعت غیرعادی (`00:00:00` = همهٔ روز را می‌بندد) |
| ۴ | ردیف‌های **بدون سفارش** — نامرئی در ووکامرس، ولی قفل می‌کنند |
| ۵ | ردیف‌هایی که سفارششان حذف شده (باید خودکار آزاد شوند) |
| ۶ | **دقیقاً همان کوئری‌ای که اعتبارسنج اجرا می‌کند** |
| ۷ | همهٔ املاهای `office_id` — اگر فاصلهٔ اضافه داشته باشد علامت می‌زند |

## امنیت

- فقط `manage_options` (مدیر) — بازدیدکنندهٔ عادی `wp_die` می‌گیرد.
- **فقط می‌خواند.** هیچ ردیفی درج، حذف یا تغییر نمی‌شود.
- ولی دادهٔ رزرو نشان می‌دهد، پس بعد از استفاده **پاکش کنید**.

## اگر ردیف مقصر پیدا شد

**ردیف با `order_id = 0`** → رزرو دستیِ رها‌شده. یا در پیشخوان حذفش کنید،
یا در phpMyAdmin:

```sql
UPDATE `Dj3i_drplus_booking` SET `deleted` = 1 WHERE `book_id` = 61;
```

(شماره را از خروجی بردارید. پیشوند `Dj3i_` را اگر فرق دارد عوض کنید.)

**ردیف با ساعت `00:00:00`** → همین کار بالا، ولی اول مطمئن شوید واقعاً رزرو نیست.

**ردیف `cancelled` که `HOLDS` می‌دهد** → باگ است. همان خروجی را بفرستید.
