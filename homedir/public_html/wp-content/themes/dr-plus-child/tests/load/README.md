# suite تست charge — مدیریت ظرفیت اتاق‌ها

این پوشه شامل تمام اسکریپت‌های تست charge و همزمانی (concurrency) برای ماژول مدیریت ظرفیت است.

## نحوه اجرا
1. محیط staging را با `setup-staging.sh` آماده کنید.
2. تست‌ها را با `run-all.sh` اجرا کنید (متغیرهای محیطی `WP_URL` و credenciales دیتابیس را تنظیم کنید).
3. نتیجه تست همزمانی الگوریتمی (بدون وردپرس) در `mock-server/RESULTS.md` موجود است و در sandbox اجرا شده است.

## مهم‌ترینInvariant
مهم‌ترین تست T7 است: ۱۰۰۰ رزرو همزمان روی یک ساعت باید دقیقاً ۲ موفقیت داشته باشد.
